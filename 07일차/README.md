## 2. 오늘의 핵심 세 줄

> **① 함수는 정의만으로 실행되지 않는다 — 호출(`이름()`)해야 실행.**
> "출력이 안 나와요" = 대부분 호출을 빠뜨린 것.

> **② `return`은 값을 돌려주고, `print`는 보여주기만 한다.**
> `return`이 없는 함수의 결과를 담으면 `None`.

> **③ 지역변수는 함수 안에서만 산다.**
> 함수 안 변수는 밖에서 못 보고, 함수 안 대입은 바깥 변수에 영향 없음.

## 3. 치트시트

### 정의와 호출 (07_01)

```python
def greet():             # 정의 (만들어 두기)
    print("점검 시작")     # 들여쓰기 = 함수에 속한 코드
greet()                  # 호출 (실제 실행) ← 이게 있어야 출력됨!
```

### 매개변수와 반환 (07_02)

```python
def report(name, temp):          # 매개변수 (받을 변수)
    print(name, temp)
report("모터", 78)                # 인자 (넣는 값), 순서 주의!
report(temp=78, name="모터")      # 키워드 인자 (순서 무관)

def add(a, b):
    return a + b                  # 값을 돌려줌
x = add(3, 4)                    # 돌려받아 담기 → 7

def stats(v):
    return min(v), max(v)        # 여러 값 반환
lo, hi = stats([...])            # 언패킹으로 받기
```

### 설계 (07_03)

```python
def status(temp, limit=90):      # 기본값 인자 (생략하면 90)
    ...
status(78)          # limit=90
status(50, 40)      # limit=40 (덮어쓰기)

def calc():
    result = 5      # 지역변수 (함수 밖에서 못 봄)
    return result   # 밖에서 쓰려면 return

def get_avg(values):
    """설명을 여기에."""          # docstring
    return sum(values) / len(values)
```

## 4. return vs print (가장 중요!)

| | `print(값)` | `return 값` |
|---|---|---|
| 하는 일 | 화면에 **보여주기만** | 값을 **돌려줌** |
| 이어 쓰기 | 불가 (값이 안 남음) | 가능 (`x = f()`로 담아 활용) |
| 함수 결과 | `None` | 돌려준 값 |

```python
def f(a, b): print(a + b)    # x = f(3,4) → x는 None
def g(a, b): return a + b    # x = g(3,4) → x는 7
```

## 5. 오늘의 함정 모음

| 함정 | 증상 | 예방 |
|---|---|---|
| 정의만 하고 호출 안 함 | 아무 출력 없음 | 함수는 `이름()`으로 호출해야 실행 |
| `return` 빠뜨림 | 결과가 `None` | 값을 돌려줄 거면 `return` |
| 인자 순서 뒤바뀜 | 오류 없이 틀린 결과 | 순서 확인 or 키워드 인자 사용 |
| 지역변수를 함수 밖에서 사용 | `NameError` | `return`으로 내보내기 |
| 호출이 정의보다 위 | `NameError` | 정의 먼저, 호출 나중 |
| `def f(a=0, b):` | `SyntaxError` | 기본값 있는 매개변수는 뒤에 |
| `return` 아래 코드 | 실행 안 됨 | `return`은 함수를 즉시 종료 |

## 6. 스스로 점검

- [ ] 함수는 호출해야 실행된다는 것을 안다 ("출력 없음" 진단)
- [ ] 매개변수와 인자의 차이를 설명할 수 있다
- [ ] 위치 인자 순서가 왜 중요한지, 키워드 인자로 어떻게 피하는지 안다
- [ ] `return`과 `print`의 차이를 예로 들 수 있다
- [ ] `return`이 없으면 결과가 `None`인 것을 안다
- [ ] 여러 값을 반환하고 언패킹으로 받을 수 있다
- [ ] 기본값 인자를 만들고 덮어쓸 수 있다
- [ ] 지역변수가 함수 밖에서 안 보이는 이유를 안다
- [ ] 작은 함수들을 조합해 큰 기능을 만들 수 있다

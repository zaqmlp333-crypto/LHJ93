## 2. 세 자료구조 한눈에

| 자료구조 | 괄호 | 특징 | 언제 쓰나 | 질문 |
|---|---|---|---|---|
| **튜플** | `( )` | 못 바꿈(불변) | 짝지어진 고정 데이터 (이름·값, 좌표) | "안 바뀌나?" |
| **셋** | `{ }` | 중복 없음, 순서 없음 | 종류 세기, 두 목록 비교 | "중복 제거/비교?" |
| **딕셔너리** | `{키:값}` | 이름으로 조회 | 이름-값 짝 (이름으로 찾기) | "이름으로 찾나?" |

> 리스트는 `[ ]`, 바뀌는 여러 값. 실무에선 넷을 **조합**해서 씁니다.

## 3. 치트시트

### 튜플

```python
s = ("모터온도", 78)      # 소괄호로 묶기
one = (78,)              # ★값 하나면 쉼표 필수★ (78)은 그냥 숫자!
name, value = s          # 언패킹 (인덱스 없이 한 번에)

# ★핵심 형태★ 튜플 리스트 + for 언패킹
sensors = [("모터온도", 78), ("펌프압력", 95)]
for name, value in sensors:     # 반복마다 이름·값 자동 분리
    if value > 90:
        print(name, "경고")
```

### 셋

```python
set(["A", "B", "A"])     # → {'A', 'B'}   중복 제거
s.add("C")               # 추가 (중복은 무시, 오류 없음)
"A" in s                 # 포함 확인 (리스트보다 빠름)

a | b   또는  a.union(b)          # 합집합 — 전체 종류
a & b   또는  a.intersection(b)   # 교집합 — 공통
a - b   또는  a.difference(b)     # 차집합 — 한쪽만 (★방향 주의 A-B≠B-A★)
```

### 딕셔너리

```python

del d["진동"]                    # 삭제
d.get("유량", 0)                 # 없는 키도 안전 (기본값)
"온도" in d                      # ★키★ 존재 확인 (값 아님!)

for name, value in d.items():    # ★가장 많이 씀★ 키·값 동시
```

## 4. 오늘의 함정 모음

| 함정 | 증상 | 예방 |
|---|---|---|
| `(78)` vs `(78,)` | 튜플인 줄 알았는데 int | 값 하나 튜플은 쉼표 필수 |
| 빈 `{}` | 셋인 줄 알았는데 딕셔너리 | 빈 셋은 `set()` |
| `del d["없는키"]` / `d["없는키"]` | KeyError | 먼저 `in`으로 확인하거나 `get` |
| 딕셔너리 `78 in d` | 값을 넣었는데 False | 딕셔너리 in은 항상 **키**를 봄 |
| `a - b` 와 `b - a` | 결과가 다름 | 차집합은 방향이 중요 |
| 튜플 `s[0] = 5` | TypeError | 튜플은 불변 (바뀔 데이터는 리스트로) |

## 5. 스스로 점검

- [ ] 튜플과 리스트를 언제 골라 쓰는지 안다 (고정 vs 변경)
- [ ] `(78,)` 의 쉼표가 왜 필요한지 안다
- [ ] 튜플 리스트를 `for name, value in ...` 로 처리할 수 있다
- [ ] 셋으로 중복 제거하고 두 목록을 비교할 수 있다 (합·교·차)
- [ ] 차집합의 방향(A-B ≠ B-A)을 안다
- [ ] 딕셔너리의 `in`이 키를 본다는 것을 안다
- [ ] `get`으로 없는 키를 안전하게 다룰 수 있다
- [ ] `items()`로 순회하며 임계값과 비교할 수 있다
- [ ] 중첩 딕셔너리에서 키를 두 번 써서 값을 꺼낼 수 있다

## 2. 오늘의 핵심 세 줄

> **① 예외가 나면 그 줄에서 멈춘다 — `try-except`로 멈추지 않게.**
> 센서 데이터 1000줄 중 한 줄이 이상해도 전체가 죽지 않게.

> **② 불량만 건너뛰려면 `try`를 반복문 '안'에 두고 `continue`.**
> 밖에 두면 첫 불량에서 전체가 중단된다.

> **③ 예외는 '구체적으로' 잡는다.**
> `except:` (전부) 는 진짜 버그까지 숨긴다. `except ValueError as e:` 로.

## 3. 치트시트

### 기본 (09_01)

```python
try:
    위험한 코드              # 오류가 날 수 있는 코드만 작게
except ValueError:
    대처                   # 구체적 예외로
except (TypeError, KeyError):   # 묶어서도 가능
    대처
```

### 견고하게 (09_02)

```python
try: ...
except ...: ...
else:      # 예외가 안 났을 때만
finally:   # 무조건 마지막 (뒷정리)

# ★핵심 패턴★ 반복문 안 try+continue
for line in lines:
    try:
        total += float(line)
    except ValueError:
        continue            # 불량 줄만 건너뛰기

except ValueError as e:     # e에 원인 메시지
raise ValueError("메시지")   # 우리 규칙을 직접 강제
```

### 자주 만나는 예외

| 예외 | 언제 | 예 |
|---|---|---|
| `ValueError` | 내용 부적절 | `int("스물")` |
| `TypeError` | 종류가 틀림 | `10 + "개"` |
| `ZeroDivisionError` | 0으로 나눔 | `10 / 0` |
| `IndexError` | 리스트 범위 밖 | `[1,2,3][5]` |
| `KeyError` | 없는 키 | `d["없는키"]` |
| `FileNotFoundError` | 파일 없음 | `open("없는파일")` |

## 4. 데이터 처리 파이프라인 (09_03~04)

지금까지 배운 전부를 결합한 5단계:

```
1. 읽기   파일 → 헤더+행      (FileNotFoundError 방어)
2. 분류   행 → 설비별 딕셔너리
3. 통계   함수로 평균         (빈 리스트면 None, 0 나누기 방지)
4. 방어   try로 불량 거르고 raise로 범위 밖 차단
5. 저장   리포트를 파일로
```

→ 통합 함수로 묶고 **인자(칸 번호·범위)만 바꾸면** 온도·압력·진동을 같은 함수로 분석!
→ 10장부터 배울 **numpy·pandas가 이 과정을 몇 줄로 압축**해 줍니다. 지금 직접 해봐야 그 편리함이 느껴집니다.

---

## 5. 오늘의 함정 모음

| 함정 | 증상 | 예방 |
|---|---|---|
| `try`가 반복문 밖 | 첫 불량에서 전체 중단 | `try`를 반복문 **안**에 |
| `except:` (전부) | 진짜 버그까지 숨김 | 구체적 예외로 |
| 정상값 0개인데 나눔 | ZeroDivisionError | `if count > 0` 확인 |
| 파일 없으면 죽음 | FileNotFoundError | `try`로 잡고 빈 결과/None |
| CSV 값 그대로 비교 | 글자라서 이상 | `float()` 변환 |

---

## 6. 스스로 점검

- [ ] `try-except`가 프로그램을 멈추지 않게 하는 원리를 안다
- [ ] ValueError·TypeError·ZeroDivisionError·IndexError를 구분한다
- [ ] 불량만 건너뛰려면 `try`를 반복문 안에 둬야 함을 안다
- [ ] `else`/`finally`의 차이를 안다
- [ ] `as e`로 원인 메시지를 확인할 수 있다
- [ ] `raise`로 우리 규칙(범위 밖 값 차단)을 강제할 수 있다
- [ ] 5단계 파이프라인의 흐름을 설명할 수 있다
- [ ] 통합 함수를 인자만 바꿔 재사용하는 설계를 이해한다
